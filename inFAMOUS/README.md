# inFAMOUS на RPCS3: настоящая мышь через KAMI

Набор для игры в **inFAMOUS** (PS3) на эмуляторе **RPCS3** с мышью и клавиатурой так, как играют в шутеры на ПК:
камера идёт ровно за рукой, без стиковых «пружин» и ускорения.

Что вы получите:

* **Сырая мышь** в свободной камере и в прицеле: никакой акселерации, никакого «догона», камера останавливается там, где остановили мышь.
* **Отдельная чувствительность** прицела и способности «Точность» (приближение сильнее, значит и мышь медленнее).
* **Игра сама не доворачивает камеру**: ни при ходьбе вбок и по диагонали, ни к горизонту.
* **«Внимание»** (фокус камеры на цели) работает как задумано, камера не отбрасывает от предметов.
* **«Грозовая буря» мышью**: направление бури водите мышью вместо наклона геймпада (SIXAXIS), геймпад не нужен.
* Игра пройдена от начала до конца с этим набором.

Известная проблема одна: **стены** (подробнее в конце).

## Что нужно

| | |
| --- | --- |
| ОС и эмулятор | Windows (64-bit), RPCS3 (проверено на 0.0.43), включённый IPC (Manage → Network Services → IPC, порт 28012) |
| .NET | [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) (x64): без него KAMI не запустится |
| Игра | inFAMOUS, **европейская версия 1.00**: BCES00609, BCES00220, BCES00591 (в том числе русский репак с тем же `EBOOT`). Американский диск (BCUS98119) не поддерживается: у него другой исполняемый файл |
| KAMI | Сборка KAMI **с поддержкой JSON-профилей**: она лежит в архиве релиза (раздел [Releases](https://github.com/3941701/KAMI/releases) этого репозитория), папка `KAMI`. Стандартный KAMI без профилей не подойдёт |

Как проверить, что у вас та же версия: в `RPCS3.log` при запуске игры есть строка с хешем
`PPU-d0c3e2a107c47d20d3316325ce6f75464a8f4f1d`, этот же хеш KAMI показывает в строке `Hash` своего окна.
Если хеш другой, профиль и патч не применятся (их нельзя «подогнать» без анализа).

## Установка (5 шагов)

1. **KAMI.** Скачайте архив из [Releases](https://github.com/3941701/KAMI/releases) и распакуйте в любую папку. Программа лежит в папке `KAMI` (`KAMI.Windows.exe`).
   Скопируйте `config/config.example.json` в `KAMI\config.json` (или поправьте свой): чувствительность `0.003` рад на пиксель, прицел `0.8`, включение и выключение `F2`.
2. **Профиль.** В сборке из релиза профиль уже на месте: `KAMI\profiles\BCES00609.json`, ничего делать не нужно.
   Если у вас своя сборка KAMI, положите `profiles/BCES00609.json` в папку `profiles` рядом с `KAMI.Windows.exe`.
   Не нужна буря мышью: замените его файлом `profiles/BCES00609_no_storm.json`, переименовав в `BCES00609.json`.
   Других профилей inFAMOUS в папке `profiles` быть не должно (файлы, имя которых начинается с `_`, KAMI не читает).
   KAMI перечитывает профиль при сохранении файла; новый файл подхватывается при следующем запуске игры или KAMI.
3. **Патч RPCS3.** Положите `patches/BCES00609_patch.yml` в папку `patches` эмулятора. Откройте **Manage → Game Patches**, выберите inFAMOUS и
   **включите три пункта**:
   * `Mouse camera: no pitch auto-return`
   * `Mouse camera: no automatic turn while walking`
   * `Mouse camera: no spring-back from obstacles when the mouse is idle`

   Патчи применяются **только при запуске игры** (Stop → Boot), загрузка сохранения внутри игры не считается.
   Имя файла должно совпадать с серийником вашего диска: `<СЕРИЙНИК>_patch.yml` (например `BCES00220_patch.yml`; внутри файла
   правка идёт по хешу исполняемого файла).
4. **Управление в RPCS3** (Pads → Keyboard). Раскладка автора, под неё настроены профиль и описание:

   | действие в игре | клавиша |
   | --- | --- |
   | движение | W A S D |
   | прыжок (Cross) | Пробел |
   | Triangle / Square / Circle | E / F / левый Ctrl |
   | R1 (стрельба) | **U** (KAMI подставляет её на левую кнопку мыши, `Mouse1Key`) |
   | L1 (прицел) | **T** (KAMI подставляет её на правую кнопку мыши, `Mouse2Key`) |
   | L2 / R2 | R / боковая кнопка мыши «вперёд» |
   | **D-pad вниз** (Грозовая буря) | **средняя кнопка мыши** |
   | D-pad вверх («Точность») | Q |
   | D-pad влево / вправо | стрелки |
   | L3 / R3 | V / B |

   Кнопки мыши привязаны через KAMI (`Mouse1Key = 85` это клавиша U, `Mouse2Key = 84` это клавиша T): мышь и KAMI в RPCS3 вместе иначе не работают.
5. **Играйте.** Запустите игру, затем KAMI. Когда KAMI нашёл игру и профиль, в строке `KAMI Status` стоит `Ready`.
   **F2** включает мышь (`KAMI Status: Injecting`, камера под контролем мыши) и выключает её (при выключенном работает обычное управление).

## Грозовая буря мышью

Зажмите кнопку D-pad вниз (по таблице: средняя кнопка мыши). Пока она зажата, камера замирает, а мышь по горизонтали
ведёт направление бури, как руль: угол сохраняется, пока вы не поведёте дальше. Отпустите кнопку, и камера снова слушается мыши.

Чувствительность и предел угла (по умолчанию ±1.2 рад) задаются первой камерой «storm» в профиле (`scale`, `min`, `max`),
направление мыши меняется знаком `sign` (в этом профиле уже подобрано так, что мышь вправо ведёт бурю вправо).

## Что настраивать

| что | где | значение |
| --- | --- | --- |
| скорость камеры | `config.json` → `Sensitivity` | рад на пиксель, по умолчанию `0.003` |
| скорость в прицеле | `config.json` → `ScopedSensitivity` | `0.8` (множитель к `Sensitivity`) |
| скорость в «Точности» | профиль → камера `precision` → `scale` | `0.2` (приближение сильнее, мышь медленнее) |
| порог «Точности» | профиль → `when ... value` | `0.5` (параметр FOV меньше этого значения) |
| инверсия | `config.json` → `InvertX` / `InvertY` | `false` |

Игру перезапускать после правки профиля не нужно (если KAMI не заметил изменений, перезапустите только KAMI).

## Как это работает (коротко)

* KAMI пишет углы камеры прямо в память игры, поэтому мышь «сырая». Профиль подсказывает, где эти углы лежат (цепочки указателей),
  как менять их для обычной камеры, прицела и «Точности».
* У игры есть собственные «подтяжки» камеры: возврат к горизонту, доворот по направлению ходьбы, отбрасывание от
  предметов. С мышью они дерутся с KAMI и дают тряску. Патч RPCS3 их выключает (три пункта выше).
* Для бури игра берёт угол из датчика наклона геймпада; профиль подставляет туда угол от мыши.

## Известные проблемы

* **Стены.** У некоторых стен и ниш камера «проседает» внутрь или резко разворачивается. Для стика игра делает отдельный
  обход стен, а для абсолютных углов мыши он не включается. Решения без потери «сырости» мыши пока нет.
* Профиль и патч рассчитаны на исполняемый файл версии 1.00 (хеш выше). Для других версий нужны другие адреса.

## Если не работает

1. `KAMI Status: Unconnected`: KAMI не видит эмулятор. Проверьте, что IPC включён и игра запущена.
2. `KAMI Status: Connected`, но не `Ready`: игра найдена, а профиль нет. Он должен лежать в `profiles` **рядом с KAMI.Windows.exe** и называться `BCES00609.json`,
   а `Hash` в окне KAMI должен совпадать с хешем выше.
3. `Ready`, но мышь не крутит камеру: нажмите **F2**, должно стать `Injecting`.
4. Мышь крутит камеру, но она трясётся при ходьбе: патч не применился. Остановите игру, проверьте имя файла патча и три галочки, запустите заново (**Stop → Boot**).
5. Буря не слушается мыши: зажимайте именно кнопку, привязанную к D-pad вниз (в таблице это средняя кнопка мыши).

### In short (English)

Mouse-look for **inFAMOUS (PS3, EU v1.00, RPCS3)** through KAMI: a JSON profile that writes the camera angles directly (raw,
unaccelerated mouse, separate sensitivity for aiming and Precision), an RPCS3 patch (three entries) that switches off the
game's own camera pulls, and mouse steering of the **Lightning Storm** (normally SIXAXIS tilt). Needs a KAMI build with profile
support (included in the release archive, needs the .NET 8 Desktop Runtime x64), the d-pad Down button bound to a key or mouse button, and the executable hash
`PPU-d0c3e2a107c47d20d3316325ce6f75464a8f4f1d`. Known issue: camera near some walls.
